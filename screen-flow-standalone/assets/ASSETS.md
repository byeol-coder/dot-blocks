# DOT BLOCKS visual assets

- `intro-bg.webp`: intro and mode-selection background image.
- `play-bg.webp`: gameplay shell background image. All live text, controls and the playable board remain HTML/CSS/Canvas layers.
- `items/*.svg`: transparent scalable special-item symbols. The default tetrominoes are not bitmap assets; they are rendered by Canvas so movement, rotation, contrast and responsive sizing remain reliable.

The source background images were generated for this project. The item SVG files are original project assets and may be used with the project.

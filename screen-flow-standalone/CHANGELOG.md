# Changelog

## GitHub Pages 음성 안내 지연 제거

- `TW_TTS`는 `/api/tts` 서버 엔드포인트를 우선 시도하는데, 이 엔드포인트는 Dot Games 호스트
  플랫폼에만 존재함. GitHub Pages(`*.github.io`)나 `file://`로 열면 매번 404 후 브라우저
  음성으로 폴백하느라 첫 안내까지 약 272ms가 밀림
- `speak()`에 호스트 판별을 추가해 `github.io`/`file://`에서는 `TW_TTS`를 건너뛰고
  `speechSynthesis`로 직행 (첫 음성까지 272ms → 40ms). 그 외 호스트(닷게임즈 플랫폼 등)는
  기존과 동일하게 `TW_TTS` 사용 — dot-minesweeper/dotfootsteps와 같은 패턴
- 음성이 이 게임의 주 피드백 채널이라 안내마다 밀리는 지연이 특히 중요했음

## 순수 배경 적용 · 인트로 문구 축약

- 텍스트·버튼이 구워지지 않은 순수 배경 5종으로 교체 (인트로/플레이 각 가로·세로, 설정·결과용)
- 인트로 모바일 배경은 빈 공간이 **상단**이라 문구를 상단 정렬로 변경하고 스크림 방향도 반전 (기존 하단 정렬은 그림과 겹쳤음)
- 플레이 배경이 중앙부가 밝아 `.stage::before` 스크림을 단색에서 그라데이션으로 교체, 모바일은 중간 밝은 띠에 맞춰 별도 가중
- 설정 서랍·일시정지·결과 오버레이에 `panel-bg.webp` 적용 (밝은 쪽이 왼쪽, 서랍은 오른쪽 어두운 면에 위치)
- 인트로 문구 136자 → 76자로 축약 (아이브로우 16→8, 설명 76→27, 키 안내 44→20)
- 블록 색상은 테트리스 표준 배색과 겹치지 않도록 기존 독자 팔레트를 그대로 유지

## 레트로 칩튠 배경음악 프리셋 추가

- 설정 서랍에 「배경음악 스타일」 선택 추가 — 기본(앰비언트) / 레트로(칩튠) 중 선택, localStorage에 저장
- 레트로 프리셋은 퍼블릭 도메인 러시아 민요 「코로베이니키」(1861) 선율을 자체 편곡한 8마디 128스텝 루프
- 사각파 멜로디 + 삼각파 루트·5도 교대 워킹 베이스 + 오프비트 하이햇으로 구성
- 기존 절차형 엔진의 템포·위험도 반응(레벨/danger에 따라 최대 146BPM까지 가속)을 그대로 계승
- 블록 퍼즐 모드에서는 퍼커션을 빼고 삼각파로 부드럽게 연주
- 시각장애인 사용자의 방향 효과음·음성 안내를 가리지 않도록 음악 게인을 효과음보다 낮게 유지하고 기존 TTS 자동 감쇠 그대로 적용
- `audio-engine.js` 스케줄러 루프 길이를 프리셋별로 가변 처리 (기본 32스텝 / 레트로 128스텝)
- `AUDIO-LICENSE.md`에 멜로디 출처·편곡 창작성·상표 비관련 고지 명시

## 아케이드 게임감 강화 (라인 클리어·콤보·레벨업 연출)

- 라인 클리어 시 "N줄 클리어 / 콤보 ×N / 테트리스! / 레벨 N!" 팝업 콜아웃 추가 (Drop 모드·Puzzle 모드 모두)
- 3줄 이상 동시 클리어 시 보드 화면 흔들림 효과 추가
- 하드 드롭 착지 시 보드에 미세한 임팩트 바운스 추가
- 점수·줄·레벨·최고 기록 HUD 숫자가 바뀔 때 팝 애니메이션으로 강조
- 다음/보관/트레이 블록 미리보기가 갱신될 때 팝인 애니메이션 추가
- 모든 신규 연출은 `prefers-reduced-motion`에서 자동 비활성화되고, 기존 점수 계산·TTS 안내·오디오 타이밍은 변경 없이 유지

## UI/UX 세련화 패스 (톤앤매너·인터랙션·레이아웃)

- CTA 그라데이션 3곳이 서로 다른 값으로 드리프트되어 있던 것을 `--cta-1`/`--cta-2`/`--cta-glow` 토큰 하나로 통일 (인트로 시작 버튼, 플레이 헤더 로고, 오버레이 확인 버튼)
- 반복되던 플레이 화면 패널/보더 블루를 `--panel-deep`, `--panel-deep-2`, `--line-blue`, `--line-blue-soft` 토큰으로 정리
- 화이트 텍스트 대비 CTA 그라데이션 시작색 대비를 2.91:1 → 3.84:1로 개선 (WCAG AA 큰글자 기준 충족)
- 일시정지·결과 오버레이의 유니코드 글리프(Ⅱ, ★)를 기존 아이콘 시스템과 통일된 인라인 SVG(일시정지, 트로피)로 교체
- 홈/메뉴/드로어 닫기 버튼과 기본 `.btn`, 플레이 컨트롤바 버튼을 44px 터치 타깃 기준으로 상향
- 버튼·모드 카드·토글·트레이 조각·드로어 닫기에 hover/press 트랜지션 추가 (기존에는 트랜지션이 전무했음)
- 인트로/플레이 화면, 설정 드로어, 일시정지·결과 오버레이에 `[hidden]` 기반 자동 진입 애니메이션 추가 (JS 변경 없이 CSS만으로 구현)
- reduced-motion 리셋 규칙이 참조만 하고 정작 구현되지 않았던 위험 단계 상태 점 펄스 애니메이션을 신규 구현
- `prefers-reduced-motion` 규칙을 새 애니메이션까지 포괄하도록 확장

## Screen-separated UI edition

- 인트로, 플레이, 일시정지, 결과 화면을 독립된 UI 상태로 분리
- 플레이 화면에서 조작법과 설정을 제거하고 핵심 점수·보드·4개 버튼만 유지
- 조작법, 닷패드 기능키, 오디오 및 접근성 설정을 오른쪽 설정 서랍으로 이동
- 인트로와 플레이 배경을 WebP 이미지 자산으로 연결
- 기본 블록을 Canvas 기반 셀 조합으로 유지하고 입체 하이라이트 렌더링 개선
- 별, 폭탄, 무지개, 랜덤 특수 아이템 SVG 자산 추가
- 모바일 모드 카드, 세로 보드, 퍼즐 트레이, 하단 핵심 컨트롤 반응형 재구성
- 홈, 설정, 일시정지, 재시작, 결과 흐름과 키보드 포커스 이동 추가

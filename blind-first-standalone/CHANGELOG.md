# Changelog

## Blind-first polished edition

- 시각장애인 사용자 기준으로 촉각 부호 재설계
- 고정/현재/착지/배치불가 블록을 서로 다른 핀 질감으로 구분
- 촉각 표면 스캔과 열 높이 상세 음성 추가
- 스테레오 방향 및 높이 기반 이어콘 추가
- CC0 Web Audio 절차형 배경음악 추가
- 음성 중 BGM 자동 감쇠
- 음성/효과음/BGM 개별 설정 추가
- 촉각 친화 잠금 유예와 3단계 속도 추가
- 블록 보관, 7-bag, 콤보 점수 추가
- 위험 높이 2단계 경고 추가
- 모바일 스와이프 조작 추가
- 백그라운드 전환 시 자동 일시정지
- 동적 Canvas aria-label 및 assertive 위험 알림 추가
- 진단 API `getAccessibilityState()` 추가
